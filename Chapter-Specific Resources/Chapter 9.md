### 6. もう〜ました and まだ〜ていません (have already... and have not... yet)

#### Question
```
もう　(object)　（ました-verb) か。
    = have you already (verbed) (object)?
```

#### Answer

```
はい、(object)　（ました-verb)。
    = Yes, I have already (verbed) (object).

いいえ、まだ　(object)　(て-form verb) いません。
    = No, I have not (verbed) (object) yet
```

#### Already (もう) Notes
- Past event that still has an effect at present
- Use aff. past tense verb (〜ました) - same as events that happened in the past
- Applies to other frequency adverbs too
- Can put time reference (e.g. きょう before or after もう)

#### Examples
1. きのうしゅくだいを<u>しました</u>。  _I did the homework yesterday._
1. もうしゅくだいをし<u>ました</u>。    _I have already done the homework._

#### Not yet (まだ) Notes
- How things stand now
- Use neg. present ている - c.f. 〜ませんでした (only used for a finished time period)

#### Examples
1. きのうしゅくだいをし<u>ませんでした</u>。   _I did not do the homework yesterday._
1. まだしゅくだいをし<u>ていません</u>。      _I have not done the homework yet._
