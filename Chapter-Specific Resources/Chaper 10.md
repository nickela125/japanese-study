## 🧩 Grammar Notes

### 1️⃣ Comparison between Two Items
#### ❓ Question ❓

>AとBと　どちら/どっち　のほう が Adj？ 

= Between A and B, which is more (Adj)?

#### 🗣️ Answer 🗣️

>Aのほうが　Bより　Adj。　
or
Bより　Aのほうが　Adj。

= A is more (Adj) than B.

#### ✨ Notes ✨
- No modification to the adjective (unlike English: big --> bigg**er**)
- **ほう** = "more" (ish); the kanji (方) = direction
= **より** = "than" (ish)
- **どちら** (shortened **どっち**) = "which" for 2 items
- Don't rely on the order of nouns - can put the より one first, then the ほうが one


#### 📝 Examples 📝
- ちゅうごく の ほうが にほん より おおきい です

    _China is larger than Japan_

- Q: にほん と カナダ と どちら の ほうが さむい です か。

    _Q: Which is colder, Japan or Canada?_

- A: カナダ の ほうが さむい です。

    _A: Canada is colder._
    
- Q: なつ と ふゆ と どちら/どっち の ほうが すき です か？

    _Q: Which do you prefer, summer or winter?_

- A: なつ の ほうが ふゆ より すき です。

    _A: I like summer better than winter._

### 5️⃣ To become

#### 📏 Rules 📏

| Word type                                	| Rule and example                                                            	|
|------------------------------------------	|-----------------------------------------------------------------------------	|
| い-adjectives<br><br>e.g. あたたかい<br>&nbsp;<br>&nbsp; 	| い → **く**なる<br><br>あたたかくなる<br><br>_to become warm / warmer_            	|
| な-adjectives<br><br>e.g. しずか(な)<br>&nbsp;<br>&nbsp; 	| な → **に**なる<br><br>しずかになる<br><br>_to become quiet / quieter_            	|
| nouns<br><br>e.g. かいしゃいん<br>&nbsp;<br>&nbsp;       	| noun → **に**なる<br><br>かいしゃいんになる<br><br>_to become a company employee_ 	|


#### ✨ Notes ✨
- なる = to become (auxilliary verb)
- なる follows nouns or adjectives to indicate change
- Conjugate なる as normal
- なる + adjective can describe an absolute change (it became warm - i.e. not cold) or a relative change (it became warmer - i.e. still cold).
- To explicitly describe relative change, use <ruby>前<rp>(</rp><rt>まえ</rt><rp>)</rp><ruby>より = "than before" (see 3rd example)

#### 📝 Examples 📝
- <ruby>日<rp>(</rp><rt>に</rt><rp>)</rp><ruby><ruby>本<rp>(</rp><rt>ほん</rt><rp>)</rp><ruby><ruby>語<rp>(</rp><rt>ご</rt><rp>)</rp><ruby>の<ruby>勉強<rp>(</rp><rt>べんきょう</rt><rp>)</rp><ruby>が<ruby>楽<rp>(</rp><rt>たの</rt><rp>)</rp><ruby>しくなりました。

    - _Studying the Japanese language is fun now (though it was like torture before)._

- <ruby>日<rp>(</rp><rt>に</rt><rp>)</rp><ruby><ruby>本<rp>(</rp><rt>ほん</rt><rp>)</rp><ruby><ruby>語<rp>(</rp><rt>ご</rt><rp>)</rp><ruby>の<ruby>勉強<rp>(</rp><rt>べんきょう</rt><rp>)</rp><ruby>が<ruby>好<rp>(</rp><rt>す</rt><rp>)</rp><ruby>きにかりました。

### 6️⃣ Somewhere / Not Anywhere etc

#### ✨ Notes ✨
- There are other expressions similar to "something" (なにか) and "not ... anything" (なにも)
- These can take various particles that change their meaning (note: Genki is wrong)
    
    - Can take に / へ, で, が, を(, は?) (again, Genki wrong)
    - The particle refers to the verb / other that you would usually use in the sentence

- Note difference between "what/where/who did you...?" questions, and these "did you ... something/where/one?" questions.
    - e.g. <ruby>何<rp>(</rp><rt>なに</rt><rp>)</rp><ruby>たべましたか - answer with thing you ate
    - e.g. <ruby>何<rp>(</rp><rt>なに</rt><rp>)</rp><ruby>かたべましたか - answer with yes/no (+ optional: what you ate)
